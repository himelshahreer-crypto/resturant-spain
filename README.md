# Kebab Factory (Badalona)

Website for Kebab Factory: dürüms, pizza, burgers and fried tacos, delivered in Badalona.

- `design/`: the original Claude Design export (`design/index.html`). This is the source of truth for the look and behaviour and is never edited.
- `docs/NEXTJS_MIGRATION_PLAN.md`: the plan for rebuilding it as a production Next.js app.

To view the original design, serve the folder (it needs internet access to load its runtime from unpkg):

```bash
npx serve design
```
